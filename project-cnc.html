Modular Foam-Cutting CNC Machine

A modular CNC machine designed and built to manufacture aerodynamic foam mold components for Toronto Metropolitan Formula Racing. The project focused on creating a scalable, repairable, and cost-effective manufacturing platform using readily available mechanical and electronic components.

01 — Overview

Project Objective

The Problem

Toronto Metropolitan Formula Racing required a method of manufacturing foam components used during the production of aerodynamic molds. The goal of the capstone project was to develop a CNC system capable of performing this work while remaining affordable, modular, and adaptable to future manufacturing requirements.

Design Requirements

+ Total project budget of approximately $700
+ Modular mechanical construction
+ Scalable machine footprint
+ Use of readily available components
+ Repairable and replaceable hardware
+ G-code-based machine control
02 — Mechanical Design

Designing a Modular Machine Architecture

The mechanical system was designed around modularity so the CNC machine could be constructed at a smaller footprint and later expanded without replacing the entire machine. This allowed components such as motors, controllers, lead screws, and electronics to be reused across multiple machine configurations.

FRAME

Modular Structure

The frame was designed to support different machine footprints while maintaining a consistent mechanical architecture.

MOTION

Linear Motion

Stepper-driven axes were incorporated to provide controlled machine movement while using inexpensive and widely available hardware.

SERVICEABILITY

Replaceable Components

Off-the-shelf components were selected wherever possible so failed hardware could be replaced without redesigning the complete system.

SCALABILITY

Expandable Footprint

The machine architecture allowed the system to scale from approximately 2 ft × 2 ft toward larger configurations such as 4 ft × 4 ft.

03 — Electronics & Motion Control

Hardware Architecture

The electrical system was built primarily from readily available CNC and 3D-printer hardware to reduce cost and simplify replacement and troubleshooting.

Arduino Mega

Main microcontroller used to execute machine-control firmware.

RAMPS 1.4

Provided an interface between the Arduino controller, stepper drivers, motors, and machine hardware.

NEMA 17 Motors

Stepper motors provided controlled movement across the CNC axes.

04 — Software & Controls

From CAD Geometry to Machine Motion

The machine used a conventional CNC workflow in which machining operations were prepared digitally and converted into G-code before being transmitted to the controller.

01

Fusion 360

Toolpaths were programmed using Autodesk Fusion 360 CAM.

02

G-code

CAM operations were exported as G-code containing the machine movement and tool-control commands.

03

GRBL

GRBL-based firmware interpreted the G-code and generated real-time machine control commands.

04

Universal G-code Sender

UGS was used to communicate with the machine and execute batches of G-code commands.

05 — Manufacturing & Assembly

Building the Physical System

Once the mechanical design and hardware architecture were established, the machine was assembled and integrated as a complete mechatronic system. Mechanical components, stepper motors, electronics, wiring, and machine-control hardware were combined and tested together before full machining operations were run.

06 — Testing & Validation

Integrating and Testing the CNC System

Testing focused on verifying machine movement, motor operation, firmware communication, G-code execution, and the integration of the mechanical and electronic subsystems. The system was operated through Universal G-code Sender to execute machine commands and verify synchronized movement and tool operation.

07 — Final Result

A Functional Modular CNC Platform

The completed project demonstrated how low-cost off-the-shelf hardware could be integrated into a modular CNC platform for manufacturing applications. The project combined mechanical design, machine construction, electronics, embedded control, CAM programming, G-code generation, and system integration into a single engineering system.
